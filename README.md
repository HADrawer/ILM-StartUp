# ILM React Demo

A polished frontend-only React prototype for ILM, a Bahrain/GCC academic operating system that combines course management, secure exams, live classes, and academic AI tools.

## Run Locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in your terminal.

## Demo Roles

- Product intro: explains ILM's five modules and value proposition.
- Login as Student: opens the student command center, course hub, live class studio, and secure exam center.
- Login as Doctor: opens the instructor command center, AI detector, AI generator, secure exam, live class, and analytics views.

All content is static mock data. No backend, database, authentication service, or external API is connected.

## Design Direction

The redesign uses a restrained Gulf-inspired system: deep navy for trust and institutional weight, pearl/sand surfaces for warmth, teal for primary action, academic green for success, warm gold for warning/readiness, and coral/date tones for review risk.

The interface is organized around clarity, role-specific next actions, visible status feedback, large clickable targets, accessible contrast, and reduced context switching across learning, exams, live class, and AI workflows.
